# 安裝人員審查

作者：Neil Mitchell
創作者： Neil Mitchell
最後修改者：Neil Mitchell

根據 GStack 審查清單審查了新應用程序，包括獨立的唯讀安全審查。所有已確定的實施問題已在授權安裝人員的工作中解決：

- 遺失的可執行檔可能會阻止選擇用戶端進行崩潰復原。現在，資料夾選擇會在檢查 WoW.exe 之前發現並驗證復原記錄。 GUI 迴歸測試涵蓋了缺少可執行檔的情況。
- 下載發生在操作鎖定之前。現在，一項租約透過提交涵蓋了下載快取；在該租約內檢查待恢復。
- 可預測的可寫暫存檔案可以遵循 NTFS 硬連結。日誌和組件臨時檔案現在使用帶有 CreateNew 的 GUID 名稱。恢復的部分檔案以獨佔方式打開，並在任何截斷或寫入之前檢查其連結計數。實際的硬連結回歸測試證明不相關的文件保持不變。
- 被篡改的復原日誌可能會在驗證之前在另一個根下建立鎖定。現在，在取得復原鎖定之前會驗證大小、位置、根目錄、區域設定、條目和範圍路徑。回歸測試證明沒有創建外來鎖。
- 中斷恢復沒有自己的可恢復狀態。 RESTORING 在突變之前被記錄並在整個 UI 和恢復路徑中被識別。每個恢復步驟通過後進行故障注入。
- 安裝/恢復的地圖選項可能在使用者介面中保持陳舊。每次成功操作後都會刷新客戶端檢測。 GUI 測試安裝地圖選擇、驗證其保留狀態、恢復並驗證先前狀態。

GitHub 遷移也會將儲存庫、發布標籤和檔案名稱固定在嵌入式目錄中。重定向是手動進行的，因此在請求之前會檢查每個 HTTPS 目標，包括憑證和連接埠檢查。舊的 Google Drive HTML 確認解析器已被刪除。新增的測試涵蓋目錄 URL 篡改、重定向可恢復傳輸和拒絕的重定向目標。

對遷移的獨立審查發現，Python 最佳化可以刪除以斷言形式編寫的發布檢查。上傳、目錄刷新和發布門檢查現在會引發明確的異常。上傳程式還解析每個來源並要求直接保留在有效負載目錄中。發布防護測試通過了 `python -O` 下的檔案路徑、大小、雜湊值和遠端 URL/摘要篡改。

最新完整回歸套件：`reports/tests-20260911-200603/results.json`; 38 測試組通過，包括 108 實際夾具安裝/恢復組合、所有提交/恢復中斷點、路徑/連接/硬鏈接保護、進程和文件鎖定、軟件/漂移、離線版本/漂移、解決

1.0.1 UI 審查涵蓋更明亮的支援文字、更大的頁腳文字和自訂停用控制繪畫。 Native Enabled 語意保持不變；僅手動繪製禁用外觀。對初始、就緒和繁忙的 Windows 預覽進行了目視檢查。 Core.cs、Downloader.cs 和所有遊戲負載與 v1.0.0 的位元組相同。其遊戲/網路證據被保留；為此更新重新運行 Windows 回歸套件。 Wine可行性探針未透過表單構建，未建立平台支援。

發布檢查和最終二進位元資料是單獨的門。請參閱版本 VALIDATION.json 以了解證據範圍，包括從未更改的遊戲基線中保留的檢查。

它保留了 C# 事務引擎並需要經過即時身份驗證的 Linux
Wine 路徑檢查、主機程序檢查和交叉前綴鎖定的幫助程式。
幫助器拒絕連結、不明確的大小寫、受限的進程可見性和
不支援的檔案系統。 Wine 驅動器映射僅在本機之後才被接受
目標檢查。流程策略保守要求全部 WoW
要關閉的實例。重複檢查減少賽跑；他們不鎖門
不相關的程式或消除敵對的並發檔案系統變更。

重點實施審查發現嵌套安裝覆蓋和鎖定釋放
根重命名間隙後。兩者均已修復：管理路徑及其最近的路徑
現有的祖先必須保留在客戶端的本機檔案系統上，並釋放
使用已儲存的本機路徑和令牌，而不要求根仍然存在。
對應的本機測試通過。

可用空間檢查現在查詢實際的 Linux 快取和客戶端檔案系統，
而不是 Wine 的映射磁碟機根目錄。實際Wine下載安裝測試
報告的可用空間為零時，拒絕操作並保留原始文件。

和夾具交易。 W-and-shield ICO 是從
現有發佈網站的圖示。 UI 快照涵蓋初始、就緒和忙碌
州；審查了 Windows 先決條件分支並安裝了運行時
行使的路徑。沒有對缺少 .NET 的 Windows 機器進行修改以進行測試。
