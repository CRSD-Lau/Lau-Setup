НАСТРОЙКА LAU — ВЫПУСК 3.0.8

Windows: скачать LauSetup.exe.
Linux/Wine: загрузите LauSetup-Wine.zip и следуйте его README.txt.
Для Wine требуется прилагаемый модуль запуска Linux; не запускайте EXE напрямую.

1. Закройте World of Warcraft.
2. Откройте LauSetup.exe и выберите папку WoW.
3. Выберите визуальные эффекты и нажмите «Установить обновление».

Обновление со старой версии или тестовой версии 2? Сначала загрузите новый установщик; старые копии встраивают старый каталог.
Выберите тот же клиент и визуальные эффекты. Проверки хэша файлов обнаруживают измененные исправления.
Запустите WoW и введите /pyversion; он должен сообщить 3.0.8 Lau.

Установщик определяет язык вашего клиента и конфигурацию модели HD.
Усиленное освящение выбрано по умолчанию. Снимите флажок для акции
внешний вид; само заклинание все еще работает. Новые визуальные эффекты заклинаний требуют
существующий клиент совместимой модели HD. Обновленные карты/миникарта не являются обязательными.

Вам нужен существующий клиент WoW 3.3.5a, сборка 12340, на Windows 10 или 11.
Эта загрузка представляет собой обновление, а не полный клиент или языковой пакет.
Необходимый совместимый файл WoW.exe устанавливается автоматически.

Никакого ручного копирования или переименования патчей не требуется. Не скачивайте весь
общий выпуск данных. Приложение загружает только те файлы, которые необходимы по вашему выбору.

Резервные копии и возобновляемые загрузки остаются в LauSetupBackups внутри вашего WoW.
папка, вне данных. Чтобы отменить обновление, закройте WoW, снова откройте LauSetup.exe,
выберите ту же папку и нажмите «Восстановить предыдущую установку». Восстановление также
работает, если в результате прерванного обновления WoW.exe временно отсутствует.

Ваши дополнения, SavedVariables, шрифты, изображения для входа в систему, настройки области и
несвязанные патчи сохраняются. Никакого брендинга Pizza Warriors, личного
В комплект поставки входят установка ElvUI, LoginUI, данные учетной записи или полный игровой клиент.

Загрузки происходят из выпусков GitHub; учетная запись GitHub не требуется.
Если загрузка прекратится, повторите попытку позже. Проверенные файлы
используются повторно, и частичная загрузка возобновляется. Файлы игры изменяются только после
все необходимые загрузки прошли проверку. Сохраните LauSetupBackups, если
приложение сообщает, что необходимо восстановление.

Настройка 1.1.7: новые визуальные эффекты заклинаний отключены, а Patch-S остается как .mpq.disabled рядом с
свой первоначальный путь. Другая отключенная копия никогда не перезаписывается.
Чтобы отменить полную установку, используйте «Восстановить предыдущую установку». Для файлов
уже удалены более старыми версиями установки, восстановите их из этих резервных копий.
используйте «Восстановить предыдущую установку» перед переустановкой. Сохраните LauSetupBackups.

Текущий файл S всегда имеет расширение .mpq.disabled. Если пожилой инвалид
копия существует, программа установки сначала сохраняет ее как `.mpq.disabled.<12-character hash>`. Без переименования вручную
необходим для переключения опций. Повторное включение вручную требует удаления
.disabled и любой следующий хэш, с закрытым WoW и без других активных
файл перезаписывается. Используйте «Восстановить предыдущую установку» для управляемого отката.

1.1.7 Исправление: включение новых визуальных эффектов заклинаний повторно использует соответствующий отключенный Patch-S без его повторной загрузки. Обычная отключенная копия перемещается в проверенную резервную копию транзакции в LauSetupBackups, даже если активный Patch-S уже соответствует. Различные версии можно восстановить с помощью функции «Восстановить предыдущую установку». При выключении по-прежнему используется .mpq.disabled. Существующие архивы с хеш-суффиксами остаются нетронутыми.
