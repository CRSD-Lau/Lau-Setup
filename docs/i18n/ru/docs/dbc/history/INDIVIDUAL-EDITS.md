# Отдельные изменения Patch-Y DBC: базовая версия Andre для сохранения многоязычной сборки Lau.



<a id="read-the-chronology-first"></a>

## Сначала прочтите хронологию

В Andre намеренно опущен **Spell.dbc** из-за конфликтов локализации, согласно Lau. Сохраненные архивы Andre 3.0.3 действительно содержат шесть визуальных/модельных DBC; они не содержат Spell.dbc. Первоначальное дополнение Lau ввело языковую зависимость. Lau и Andre вместе отладили проблему, и многоязычная перестройка разрешила ее.

Lau идентифицирует эти вехи разработки как 3.0.4 (первоначальное добавление) и 3.0.5 (многоязычное исправление), при этом 3.0.6 – 3.0.8 представляют собой исправления, номера версий которых были изменены. Сохраненные артефакты не совсем соответствуют этому воспоминанию: опубликованная базовая версия с пометкой 3.0.4 уже содержит многоязычное исправление. В этом отчете артефакты и хэши именуются явно, а не автоматически присваиваются опубликованному ярлыку ранней сломанной сборки.

[Доказательство на этапе локализации](../../../../../dbc/history/localization-stage.json) сравнивает четыре сохраненных архива версии 35 до локализации с многоязычными версиями: только Spell.dbc изменения, все числовые поля остаются идентичными, а существующие визуальные ссылки сохраняются. HD New Spells Off был собран отдельно с использованием стандартных числовых данных.

<a id="format-and-scope"></a>

## Формат и область действия

Это сравнение передачи обслуживания Patch-Y, а не аудит каждого отдельного конвейера локализации Q/S/map. В шести выпусках CSV перечислены отдельные изменения таблицы/записи/поля, а также все добавленные значения записей. Два общих файла JSON gzip содержат декодированные изменения текста заклинания без дублирования текста для вариантов освящения. Каждая текстовая ячейка — `[record_id, zero_based_field, old_string_index, new_string_index]`; разрешите последние два через массив `strings` этого файла.

Числовые значения представляют собой необработанные слова без знака 32-bit, включая шаблоны битов с плавающей запятой; неизвестные имена схем не угадываются. Поле Spell.dbc 131 — это визуальная ссылка, используемая сценариями сборки. Смещения строк декодируются перед сравнением. Добавленный Spell.dbc использует сохраненные данные HD Patch-S для HD New Spells On и стандартные данные, извлеченные с сервера для HD New Spells Off и Non-HD. Унаследованные строки не засчитываются как вновь созданные записи.

<a id="what-the-edit-groups-mean"></a>

### Что означают группы редактирования

- Поле заклинания 131: пятнадцать принятых визуальных ссылок на индикатор рейда в каждом издании.
- Текстовые ячейки заклинаний: многоязычное/резервное количество слотов; эти подсчеты не учитывают вновь написанные переводы.
- SpellVisual, SpellVisualKit и ряды прикреплений: маршрутизация индикаторов, комплекты и настройка прикрепления модели.
- SpellVisualEffectName: добавлены ссылки на модели и различия во внешнем виде Consecration.
- CreatureDisplayInfo и CreatureModelData: без изменений по сравнению с соответствующим базовым уровнем Andre.
- HD New Spells Off: частный комплект Rimefang использует 90059 для сохранения исходного комплекта 90046.
