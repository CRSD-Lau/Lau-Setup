Многоязычный текст заклинания, широкоэкранное изображение загрузки, пользовательские индикаторы местности и дополнительные карты HD для **WoW 3.3.5a, сборка 12340**. **Установщик 1.1.7 · Версия игры 3.0.8 Lau · Девять языков клиента**

<a id="patch-s-stays-recoverable"></a>

## Patch-S остается восстанавливаемым

**Исправление установки 1.1.7:** повторное включение новых визуальных эффектов заклинаний повторно использует соответствующий отключенный Patch-S и перемещает простую отключенную копию в `LauSetupBackups`, поэтому данные не сохраняют активный/отключенный дубликат. Различные копии сохраняются в резервной копии транзакции. При выключении по-прежнему используется `.mpq.disabled`. Для восстановления используйте **Восстановить предыдущую установку**.

<a id="90-breath-and-slime-spray-warnings"></a>

## 90° Предупреждения о дыхании и брызгах слизи

**3.0.8 Lau:** все поддерживаемые индикаторы дыхания и спрей Rotface Slime Spray соответствуют **90° в целом** после подтверждения тестера Warmane. Охватывает Халиона в обоих мирах: Савиану Ярости Огня, Сартариона, ICC Злобного Клыка и Синдрагосу. Диапазон и время анимации сохраняются. Утвержденный больший радиус метеорного огня Halion и светло-голубое Coldflame остались без изменений.

**Уже установлено?** Сначала загрузите **Setup 1.1.7**, выберите ту же папку и визуальные элементы, затем установите. Программа установки проверяет действительные хэши SHA-256: обнаруживается даже однобайтовое изменение с тем же размером и меткой времени. Только соответствующие новые файлы считаются уже установленными. `/pyversion` сообщает **3.0.8 Lau**. Старые установщики сохраняют свой старый встроенный каталог.

<a id="get-started"></a>

## Начать

1. **Закройте WoW полностью.** В Wine закройте каждый экземпляр WoW во всех префиксах.
2. **Запустите установку и выберите папку клиента.** Windows: откройте `LauSetup.exe`. Linux: извлеките все четыре файла из ZIP-архива Wine и используйте панель запуска ниже.
3. **Выберите визуальные эффекты и установите.** Запуск Enhanced Consecration отмечен галочкой; снимите флажок для стандартного внешнего вида. Для новых визуальных эффектов заклинаний требуется совместимая базовая модель HD. Карты не являются обязательными.
4. **Запустите WoW и запустите `/pyversion`.** Прежде чем войти в игру, подтвердите установленную версию.

На Linux запустите это из извлеченной папки с существующим префиксом:

```sh
WINEPREFIX="/absolute/path/to/your/existing/prefix" sh LauSetup.sh
```

Используйте лаунчер как обычный пользователь. Он проверяет Linux пути, запуск игр, свободное место и блокировки установщика по префиксам. Используйте локальный Linux хранилище; связанные папки, общие сетевые ресурсы и Windows-монтированные диски не поддерживаются. [Wine гид](wine/README.md) перечисляет шрифты и все необходимые условия.

В Windows программа установки предлагает официальную страницу загрузки Microsoft .NET Framework 4.8, если среда выполнения отсутствует. В протестированной конфигурации Wine используется **Wine Mono**, а не установщик Windows .NET.

<a id="restore-with-your-backups"></a>

## Восстановление с помощью резервных копий

Закройте WoW, снова откройте программу установки через ту же программу запуска, выберите тот же клиент и выберите **Восстановить предыдущую установку**. Сохраните `LauSetupBackups` в папке клиента: там находятся оригиналы и записи восстановления.

Прерванную установку или восстановление можно восстановить, даже если `WoW.exe` временно отсутствует. Если другое обновление изменило установленные файлы, восстановление останавливается и сохраняет резервную копию для разрешения. После того как этот установщик добавит обновление карты, он сохранит его при изменении редакции; восстановите предыдущую установку, чтобы отменить это обновление.

<a id="tested-with-clear-limits"></a>

## Протестировано, с четкими ограничениями

Выпуск 1.1.7 прошел **группы регрессии 50 на Windows и на Wine**, включая 108 планы локализации/издания/карты для каждой платформы. Релиз игры 3.0.8 ранее прошел шесть обновлений и однобайтовое обнаружение на обеих платформах; его полезная нагрузка не изменилась. Настройка 1.1.7 также охватывает последовательность включения всех флагов и отключения новых заклинаний со старыми отключенными копиями, повторяющимися переключениями и точным откатом. Публичные полезные данные загружались анонимно и проверялись по хешу; Были протестированы фактическая установка ядра и откат.

Wine был протестирован с **Wine 11.0 / Wine Mono 10.4.1** на локальном хранилище Linux, включая прилагаемый модуль запуска, как обычный пользователь. Геометрия метеорного огня Halion точно соответствует утвержденной тестировщиками версии 2. Холодное пламя, дорожки анимации, собственный огонь и таблицы заклинаний остаются байтово-идентичными 3.0.7. Анимация веб-сайта представляет собой иллюстративный макет. Эти тесты не подтверждают каждый дистрибутив Linux или встречу в игре.

Интеграция Lutris, Proton и macOS не входит в этот выпуск. Исполняемый файл не имеет цифровой подписи.
