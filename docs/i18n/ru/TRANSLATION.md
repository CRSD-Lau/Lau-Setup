# Переводы репозитория

Действие **Перевести документацию** GitHub использует **бесплатный веб-сайт Google Translate**, чтобы документация репозитория была доступна на всех поддерживаемых языках игры, а также на **бразильском португальском**. Никакого ключа API, платной учетной записи Cloud Translation, подписки или загрузки модели не требуется.

Используйте языковые ссылки в верхней части README. GitHub по умолчанию отображает корневой README; посетители выбирают свой язык, используя эти ссылки. В ходе этого рабочего процесса осуществляется перевод документации, включая руководства по установке и технические ссылки. Он не переводит интерфейс GitHub, проблемы, описания выпусков, отдельный веб-сайт или интерфейс установщика, а также не добавляет португальский языковой стандарт игры.

<a id="languages"></a>

## Языки

Покрытие проверяется по `build/catalog.json`, при этом `ptBR` добавляется для документации. Варианты чтения: английский, немецкий, испанский для Испании и Мексики, французский, корейский, русский, упрощенный китайский, традиционный китайский и бразильский португальский.

Селектор веб-языка Google идентифицирует `pt` как португальский (Бразилия); Португальский (Португалия) – другая цель. Google предоставляет одну цель `es`, поэтому на страницах Испании и Мексики используется один и тот же общий перевод на испанский язык. Китайские цели являются отдельными. Целевые коды Google и названия родных языков находятся в `tools/translation-locales.json`. Для добавления локали игры требуется добавление сопоставления документации; отсутствующее покрытие не проходит проверку.

<a id="automatic-updates"></a>

## Автоматические обновления

Нажатие на изменение документации на английском языке, каталога или инструментов перевода запускает действие. Специалисты по сопровождению также могут выбрать **Действия → Перевести документацию → Запустить рабочий процесс → Основной**. Он обнаруживает отслеживаемые Markdown и текстовые файлы в корне репозитория и `docs/`, а также `wine/README.txt`. Сгенерированные переводы и `AGENTS.md` исключены. Текстовые руководства отображаются в формате Markdown под `docs/i18n/<language>/`.

Переводу подлежат только измененные документы. Хэши источника и вывода, а также кэш сегментов позволяют избежать повторных запросов. Увеличьте `TRANSLATION_REVISION` при изменении соглашений о переводе. Одновременно выполняются не более трех языковых заданий с паузой между запросами в каждом задании. Ограничение скорости останавливает затронутое задание; повторите попытку позже. Бесплатный веб-интерфейс неофициален для автоматизации и может изменять или блокировать запросы. Платного резервного варианта нет. Существующие опубликованные страницы остаются доступными даже в случае сбоя генерации.

Стандартное выполнение бегуна, размещенного на GitHub, для этого общедоступного репозитория бесплатно. Задания отключаются, если репозиторий становится частным. Срок действия небольших промежуточных артефактов истекает через один день; никакая модель или большая зависимость не сохраняются.

<a id="integrity-and-publication"></a>

## Честность и публикация

Код, команды, URL-адреса, номера версий, названия продуктов, сведения об авторстве и статусе подписи защищены. Относительные ссылки на документы указывают на один и тот же язык, а ссылки на изображения и код указывают на оригиналы. Стабильные английские привязки заголовков сохраняют ссылки на разделы. Каждая страница идентифицирует себя как автоматический перевод, ссылается на английский источник и сохраняет метаданные «Автор», «Создатель» и «Кем последнее изменение» для **Neil Mitchell**.

Все девять переведенных вариантов чтения должны пройти проверку целостности источника/вывода перед публикацией в `main`. Публикация отказывается от измененной версии исходного кода и никогда не навязывает ее принудительно. Запросы на вытягивание запускают проверки модулей и настоящий дымовой перевод README на бразильский португальский язык с доступом только для чтения. Если в дальнейшем защита веток препятствует фиксации, адаптируйте публикацию к утвержденному процессу PR.

Машинный перевод по-прежнему нуждается в проверке беглого читателя. Английский остается авторитетным. Для долгосрочных исправлений обновите английский источник или инструменты перевода; прямые изменения в сгенерированных файлах будут восстановлены. Неудачные или неполные пакеты не заменяют существующие документы.

<a id="local-use"></a>

## Локальное использование

Достаточно Python 3.11 или новее; никаких дополнительных пакетов не требуется. Проверить структуру без доступа к сети:

```sh
python -m unittest discover -s tests -p test_translate_docs.py -v
python tools/translate_docs.py --check
```

Переведите общедоступную документацию с помощью бесплатного веб-сайта Google:

```sh
python tools/translate_docs.py --locale ptBR
python tools/translate_docs.py --navigation
```

Ссылки: [Google Translate](https://translate.google.com/), [GitHub Оплата действий](https://docs.github.com/en/billing/concepts/product-billing/github-actions). Отдельный [Google Cloud Translation API](https://cloud.google.com/translate/pricing) является платной услугой и здесь не используется.
