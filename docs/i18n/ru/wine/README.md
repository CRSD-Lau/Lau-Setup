Lau Setup для Wine на Linux
Author / Creator / Last Modified By: Neil Mitchell

1. Используйте существующий клиент WoW 3.3.5a и создайте клиент 12340 в локальной файловой системе Linux.
2. Закройте каждый экземпляр WoW, включая игры с другими префиксами Wine.
3. Распакуйте `LauSetup.zip`. Храните вместе пять файлов из `LauSetup/`: `LauSetup.exe`, `LauSetup.sh`, `lau_wine.py`, `lau-languages.json` и `README.txt`.
4. Откройте терминал в извлеченной папке и запустите:

```sh
WINEPREFIX="/absolute/path/to/your/existing/prefix" sh LauSetup.sh
```

5. Выберите существующую папку с игрой и установите. Обычное автоматическое резервное копирование
   и Восстановить предыдущую установку.

Требования к этому выпуску:
- Wine 11.0, префикс 64-bit, и Wine Mono 10.4.1 уже установлены там.
- Python 3.9 или новее для помощника безопасности хоста (только стандартная библиотека).
- Шрифты Liberation Sans или DejaVu Sans; полный пакет шрифтов Wine должен
  также быть установлен, чтобы можно было отображать собственные элементы управления Wine Mono по умолчанию.
- Локальное хранилище Linux. Сетевые ресурсы и диски, подключенные к Windows, исключаются.
- Нормальная видимость хост-процесса. Не запускайте этот лаунчер через песочницу
  это скрывает другие процессы Wine. Запускайте как обычный пользователь, а не sudo/root.

Префикс 64-bit может содержать клиент 32-bit WoW. Этот установщик не
создайте, преобразуйте или обновите префикс Wine, установите Wine/Mono, настройте
DXVK или измените программу запуска игры. Используйте настройку Wine вашего дистрибутива.
сначала инструкции, если время его выполнения отсутствует.

Официальный пакет Wine Mono для этой протестированной среды выполнения:
https://github.com/wine-mono/wine-mono/releases/tag/wine-mono-10.4.1

Используйте среду выполнения Wine Mono с Wine. Установщик Windows .NET Framework
не входит в комплект поставки и не требуется для данной протестированной конфигурации Wine Mono.

Всегда запускайте через LauSetup.sh. Запуск LauSetup.exe непосредственно под Wine
откажется от клиентских операций без помощника Linux. Он проверяет пути хоста
а также обрабатывает и удерживает блокировку хоста, общую для префиксов Wine. Если оно остановится,
снова откройте программу запуска и восстановите ожидающую установку, прежде чем повторить попытку.

Держите WoW закрытым до завершения установки. Проверки процессов уменьшают количество гонок; они не могут
запретить другой программе запускать игру или впоследствии изменять файлы.
Символические пути, жесткие ссылки и неоднозначный регистр имен файлов отклоняются. Данные
и каталоги резервных копий должны оставаться в той же файловой системе, что и клиент.

Область проверки: изолированные клиенты Wine 11.0 / Wine Mono 10.4.1, приспособление и
тесты установки/восстановления реальной полезной нагрузки, тесты безопасности с двумя префиксами и образцы графического пользовательского интерфейса.
чеки. Это не сертификация каждого дистрибутива Linux, файловой системы,
масштаб отображения, версия Wine или игровое событие. Нет Lutris, Proton или macOS
интеграция включена в этот выпуск.

Интерфейс установщика автоматически следует языку ОС из десяти вариантов; ручной выбор сохраняется. Данные игры клиента по-прежнему поддерживают девять языков и следуют обнаруженному языку игры.

Настройка 1.1.7: новые визуальные эффекты заклинаний отключены, а Patch-S остается как .mpq.disabled рядом с
свой первоначальный путь. Другая отключенная копия никогда не перезаписывается.
Чтобы отменить полную установку, используйте «Восстановить предыдущую установку». Для файлов
уже удалены более старыми версиями установки, восстановите их из этих резервных копий.
используйте «Восстановить предыдущую установку» перед переустановкой. Сохраните LauSetupBackups.

Текущий файл S всегда имеет расширение .mpq.disabled. Если пожилой инвалид
копия существует, программа установки сначала сохраняет ее как `.mpq.disabled.<12-character hash>`. Без переименования вручную
необходим для переключения опций. Повторное включение вручную требует удаления
.disabled и любой следующий хэш, с закрытым WoW и без других активных
файл перезаписывается. Используйте «Восстановить предыдущую установку» для управляемого отката.

1.1.7 повторно включить очистку: сопоставление отключено. Patch-S повторно используется локально. Обычная отключенная копия перемещается в проверенную резервную копию транзакции в LauSetupBackups, оставляя одну активную S. Различные копии можно восстановить с помощью функции «Восстановить предыдущую установку». Существующие архивы с хеш-суффиксами не очищаются.
