# 설치자 리뷰

저자: Neil Mitchell  
제작자:Neil Mitchell  
최종 수정자: Neil Mitchell

독립적인 읽기 전용 보안 검토를 포함하여 GStack 검토 체크리스트와 비교하여 새 애플리케이션을 검토했습니다. 확인된 모든 구현 문제는 인증된 설치자 작업 내에서 해결되었습니다.

- 누락된 실행 파일로 인해 충돌 복구를 위해 클라이언트를 선택하지 못할 수 있습니다. 이제 폴더 선택은 WoW.exe를 검사하기 전에 복구 기록을 검색하고 검증합니다. GUI 회귀 테스트는 실행 파일이 누락된 경우를 다룹니다.
- 작업 잠금 이전에 다운로드가 발생했습니다. 이제 하나의 임대가 커밋을 통한 다운로드 캐시를 포함합니다. 보류 중인 복구가 해당 임대 내에서 확인됩니다.
- 예측 가능한 쓰기 가능한 임시 파일은 NTFS 하드링크를 따를 수 있습니다. 저널 및 어셈블리 임시는 이제 CreateNew와 함께 GUID 이름을 사용합니다. 재개된 부분 파일은 독점적으로 열리고 잘리거나 쓰기 전에 해당 링크 수를 확인합니다. 실제 하드링크 회귀 테스트에서는 관련되지 않은 파일이 변경되지 않은 상태로 남아 있음이 입증되었습니다.
- 변조된 복원 저널은 검증 전에 다른 루트 아래에 잠금을 생성할 수 있습니다. 이제 복원 잠금을 획득하기 전에 크기, 위치, 루트, 로케일, 항목 및 범위가 지정된 경로가 검증됩니다. 회귀 테스트를 통해 외부 잠금이 생성되지 않았음을 입증했습니다.
- 중단된 복원에는 자체적으로 재개 가능한 상태가 없습니다. RESTORING은 변형 이전에 저널링되며 UI 및 복구 경로 전체에서 인식됩니다. 모든 복원 단계를 통과한 후 오류가 주입됩니다.
- 설치/복원된 지도 옵션이 UI에서 오래된 상태로 유지될 수 있습니다. 작업이 성공할 때마다 클라이언트 감지가 새로 고쳐집니다. GUI 테스트는 맵 선택을 설치하고, 유지된 상태를 확인하고, 이전 상태를 복원 및 확인합니다.

GitHub 마이그레이션은 내장된 카탈로그에 리포지토리, 릴리스 태그 및 파일 이름을 추가로 고정합니다. 리디렉션은 수동으로 수행되므로 자격 증명 및 포트 확인을 포함하여 요청 전에 각 HTTPS 대상을 확인합니다. 이전 Google 드라이브 HTML 확인 파서가 제거되었습니다. 추가된 테스트에는 카탈로그 URL 변조, 리디렉션된 재개 가능한 전송 및 거부된 리디렉션 대상이 포함됩니다.

마이그레이션에 대한 독립적인 검토를 통해 Python 최적화가 어설션으로 작성된 게시 확인을 제거할 수 있는 것으로 나타났습니다. 이제 업로드, 카탈로그 새로 고침 및 릴리스 게이트 확인에서 명시적인 예외가 발생합니다. 또한 업로더는 각 소스를 확인하고 해당 소스가 페이로드 디렉터리 내에 직접 남아 있도록 요구합니다. 게시 가드 테스트는 파일 경로, 크기, 해시 및 원격 URL/다이제스트 변조에 대해 `python -O`를 통과합니다.

최신 전체 회귀 모음: `reports/tests-20260911-200603/results.json`; 108 실제 픽스처 설치/복원 조합, 모든 커밋/복원 중단 지점, 경로/접합/하드링크 보호, 프로세스 및 파일 잠금, 손상/드리프트, HTTP 범위 처리, 취소, 오프라인 어셈블리 및 실제 버전의 실행 파일을 사용한 GUI 설치/복원을 포함한 38 테스트 그룹을 통과했습니다.

1.0.1 UI 검토에서는 더 밝은 지원 텍스트, 더 큰 바닥글 텍스트 및 사용자 정의 비활성화 제어 그림을 다루고 있습니다. 기본 활성화 의미는 그대로 유지됩니다. 비활성화된 모양만 수동으로 그려집니다. 초기, 준비 및 사용 중인 Windows 미리보기를 육안으로 검사했습니다. Core.cs, Downloader.cs 및 모든 게임 페이로드는 v1.0.0와 바이트 동일하게 유지됩니다. 해당 게임/네트워크 증거는 유지됩니다. 이번 업데이트에서는 Windows 회귀 분석 제품군이 다시 실행됩니다. Wine 타당성 조사가 양식 구성을 통과하지 못했고 플랫폼 지원을 설정하지 않았습니다.

게시 확인과 최종 바이너리 메타데이터는 별도의 게이트입니다. 변경되지 않은 게임 기준에서 유지된 검사를 포함하여 증거 범위는 VALIDATION.json 릴리스를 참조하세요.

## 설정 1.1.7 검토

경로 범위, 로컬 소스 신뢰, 다운로드 선택, 실행 전/커밋 드리프트 검사, 트랜잭션 백업 및 롤백 호환성에 대한 현재 차이점을 검토했습니다. 해결되지 않은 결과가 없습니다. 로컬 재사용은 카탈로그 일치 루트/활성 로케일 S 쌍으로 제한됩니다. 비활성화된 파일은 기존의 확인된 백업 저널을 통해 이동됩니다. 두 플랫폼 모두 정확한 스택 롤백을 통해 50 회귀 그룹과 실제 릴리스 파일 켜기/끄기/켜기를 통과했습니다. 게임 페이로드는 변경되지 않습니다.
