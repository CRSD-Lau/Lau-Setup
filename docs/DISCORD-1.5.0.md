## Lau Setup 1.5.0 + Patch-Y 3.1.0

The new release is out!

- **77 crisp HD 16:9 loading screens**, preserving the artwork without stretching or zooming. Eight screens keep their original art.
- **Caverns of Time map fix.**
- **Updated raid visuals:** Marrowgar Coldflame, BQL Swarming Shadows, Halion Meteor Strike and selected ToC effects.
- **Enhanced Consecration is now standard** across HD and SD.
- Clearer folder errors, **Copy diagnostics**, and a better upgrade/repair summary.

Thanks to **Suppository and the source-patch contributors**, and **Andre** for the Halion mark restoration. **Lau / Lausudo (Neil Mitchell)** handled the Lau edits, adaptations and integration.

**Download:** https://github.com/CRSD-Lau/Lau-Setup/releases/latest/download/LauSetup.zip
**Changelog:** https://github.com/CRSD-Lau/Lau-Setup/releases/tag/v1.5.0

Close WoW, extract the whole ZIP and run setup. Enable **Compatible WoW.exe + loading screens** for the new loading pack. Check `/pyversion` for **3.1.0 Lau**.

I’ve tested the loading pack in game. Halion’s restored marks and other client/encounter combinations still need feedback—please report any issues with your client edition and a screenshot.
