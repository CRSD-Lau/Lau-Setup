guides. The current 1.2.0 beginner steps were inserted into every localized
primary guide while an external Google Translate refresh of older technical
text remains pending after HTTP 429. English remains authoritative until a
fluent reviewer records a result here.

## How to use this table

For a review, first select the English source revision that the reviewer will
compare. Record that revision, the reviewer, and a concise result below. Do not
fill in a revision from a later change, and do not treat an empty row as a
review. Correct durable wording in the English source or translation tooling;
generated localized files can be replaced by the translation workflow.
