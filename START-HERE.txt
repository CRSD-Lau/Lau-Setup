LAU SETUP 1.2.0 — GAME RELEASE 3.0.8
Author / Creator / Last Modified By: Neil Mitchell

Download LauSetup.zip on Windows or Linux and extract all five files together.
Windows: open LauSetup.exe.
Linux/Wine: run LauSetup.sh and follow its README.txt.
Wine requires the supplied Linux launcher; do not run the EXE directly.

Setup follows your system language. Use Interface language to select another
language; your choice is remembered for your user account. Automatic follows
the system again. This changes setup text only, never WoW's language files.

1. Close World of Warcraft.
2. Launch setup for your platform and choose your WoW folder.
3. Choose your visuals and click Install upgrade.

Updating from an older release or test v2? Download the new installer first; old copies embed the old catalog.
Select the same client and visuals. File-hash checks detect the changed patches.
Start WoW and type /pyversion; it should report 3.0.8 Lau.

The installer detects your client language and HD model configuration.
Enhanced Consecration is selected by default. Uncheck it for the stock
appearance; the spell itself still works. New spell visuals require an
existing compatible HD model client. Upgraded maps/minimap are optional.

You need an existing WoW 3.3.5a client, build 12340. Windows 10/11 needs .NET
Framework 4.8. Linux needs the supported Wine/Mono environment in README.txt.
This download is an upgrade, not a complete client or language pack.
The required compatible WoW.exe is installed automatically.

No manual patch copying or renaming is needed. Do not download the entire
shared data release. The app downloads only the files needed for your selection.

Backups and resumable downloads stay in LauSetupBackups inside your WoW
folder, outside Data. To undo the update, close WoW, reopen LauSetup.exe,
choose the same folder, and click Restore previous install. Recovery also
works if an interrupted update left WoW.exe temporarily missing.

Your addons, SavedVariables, fonts, login artwork, realm settings, and
unrelated patches are preserved. No Pizza Warriors branding, personal
ElvUI setup, LoginUI, account data, or full game client is bundled.

Downloads come from GitHub Releases; no GitHub account is needed.
If a download stops, retry later. Verified files
are reused and partial downloads resume. Game files are changed only after
all required downloads have passed verification. Keep LauSetupBackups if
the app reports that recovery is needed.

This installer is unsigned, so Windows may display an unknown-publisher
warning. Use the supplied checksum to verify your download. It does not
require disabling Windows security or installing Python/PowerShell tools.
The .NET Framework 4.8 runtime is required.

Once this installer has added the map upgrade, it keeps that upgrade during
edition changes. Use Restore previous install to undo the map installation.

Credits: Andre (Patch-Y baselines), Loriendal and Trimitor (HD foundation),
Project Reforged contributors (HD artwork), Blizzard (original artwork and
localized text), Lau (adaptation, compatibility, indicators, testing).

Setup 1.1.7: New spell visuals off keeps Patch-S as .mpq.disabled next to
its original path. A different disabled copy is never overwritten.
To undo the complete install, use Restore previous install. For files
already removed by older setup versions, recover them from those backups
using Restore previous install before reinstalling. Keep LauSetupBackups.

The current S file always becomes .mpq.disabled. If an older disabled
copy exists, Setup first preserves it as .mpq.disabled.<12-character hash>. No manual rename
is needed to switch options. Re-enabling manually requires removing
.disabled and any following hash, with WoW closed and no different active
file being overwritten. Use Restore previous install for managed rollback.

1.1.7 Hotfix: enabling New spell visuals reuses a matching disabled Patch-S without downloading it again. The plain disabled copy is moved into the verified transaction backup in LauSetupBackups, even when active Patch-S already matches. Different versions remain recoverable with Restore previous install. Switching off still uses .mpq.disabled. Existing hash-suffixed archives are left intact.


Setup 1.1.8 Hotfix checks active root and client-locale MPQs for renamed Patch-Y markers and exact copies of catalog patches before downloading and again before installation. A possible conflict or unreadable/unsupported archive stops installation with its filename; setup does not delete it. Keep a backup and resolve the named archive outside Data before retrying. Expected Q/M/S/Y placements and disabled files are excluded. Game files remain 3.0.8; no DBC edits.
