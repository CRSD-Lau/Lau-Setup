LAU SETUP 1.5.0 — LOCAL RAID VISUAL CANDIDATE
Author: Neil Mitchell
Creator: Neil Mitchell
Last Modified By: Neil Mitchell

1. Use an isolated copy of your WoW client for this candidate. Close World of Warcraft.
2. Extract the WHOLE LauSetup-1.5.0-candidate-offline.zip. Keep its files together,
   including the payload folder beside LauSetup.exe.
3. Windows: open LauSetup.exe. Linux/Wine: use the supplied launcher as
   explained in README.txt inside the packaged LauSetup folder. Both platforms use the same ZIP.
   Wine 11.0 / Wine Mono 10.4.1 remains the tested baseline; older or newer
   installed runtimes warn instead of being blocked.
4. Choose your existing WoW 3.3.5a folder — the folder containing WoW.exe.
   Click Next. The installer detects your language and HD/Non-HD client.
   enGB, ptBR and itIT clients keep their selected locale and use the
   verified English visual layer where Lau needs a visual asset. This does
   not install a language pack or translated game text.
   Use Interface language at any time if its automatic choice is wrong.
5. Choose your extras. Patch-Y is included for your detected client.
   Enhanced Consecration is included as standard; there is no separate toggle.
   Optional extras:
   - New spell visuals: upgraded spell effects; requires existing HD models.
   - Maps/minimaps: Lau's maps plus Trimitor dungeon, raid and cave maps.
     Includes the WDM support addons. Cave maps are upstream beta.
   - Compatible WoW.exe + loading screens: install both together.
     Off keeps both unchanged. Maps remain independent.
6. Click Next. Read Your choices, the folder and download size.
7. Click Install upgrade. Wait for Installed and verified.
8. Open WoW. Test the selected visuals. Installer tests alone do not prove
   in-game map compatibility, navigation or patch loading order.

YOUR FILES
Files Setup replaces are backed up in LauSetupBackups. Keep that folder.
Restore previous install puts those originals back. Use Setup 1.4.2 or newer
for backups made by this release with map-support addons.
Other patches are not parsed or removed. If you renamed a patch, manage
any duplicate yourself. Empty Patch-V is backed up; nonempty V stays with
a warning. Personal settings and unrelated addons are not changed.
The maps option may replace WDM/!Astrolabe support files and the active
language's Patch-T; their old files are backed up too.

The installer version appears at the bottom. Patch-Y/game release is 3.1.0;
the installer has its own version. A full HD model pack is not included.

Release packaging compacts only new Patch-Y downloads. Setup does not compact your existing files or backups. LauSetupBackups keeps the exact original files for Restore previous install.
