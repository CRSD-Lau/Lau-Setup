LAU SETUP 1.2.0 — GAME RELEASE 3.0.8
Author / Creator / Last Modified By: Neil Mitchell

START HERE ON WINDOWS

1. Close World of Warcraft completely.
2. Download LauSetup.zip. Right-click it, choose Extract All, and open the
   extracted LauSetup folder.
3. Double-click LauSetup.exe. In File Explorer, its type is Application.
4. In Lau Setup, click Choose folder… and select the
   game folder that directly contains WoW.exe—not its Data folder or a launcher
   folder.
5. Enhanced Consecration starts on; leave it on unless you prefer the stock
   look. New spell visuals is available only when compatible HD models are
   detected. Upgrade maps and minimap is optional and adds a download.
6. Click Install upgrade and wait for it to finish. If setup says Already
   installed, the selected files already match this release and no game update
   is needed. Otherwise start WoW and type /pyversion to confirm 3.0.8 Lau.

START HERE ON LINUX / WINE

Use the same LauSetup.zip, but first have Wine 11.0, Wine Mono 10.4.1, an
existing 64-bit Wine prefix, Python 3.9+, the documented fonts, and local Linux
storage. Extract the ZIP, close every WoW instance in every prefix, then run:

  WINEPREFIX="/absolute/path/to/your/existing/prefix" sh LauSetup/LauSetup.sh

Never run LauSetup.exe directly under Wine. After setup opens, use the same
Choose folder…, options, and Install upgrade steps above.

IF YOU GET STUCK

- Cannot find LauSetup.exe? Extract the ZIP first and open the LauSetup folder;
  its type should be Application.
- Setup rejects a folder? Select the folder that directly contains WoW.exe.
- WoW is running? Close it and retry; on Wine, close every WoW instance in
  every prefix.
- Windows says .NET is missing? Use the Microsoft .NET Framework 4.8 prompt,
  then reopen setup.
- Setup says matching language files are missing? Use the fully installed game
  locale already active in that client; changing a config value does not add a
  language pack.
- Setup says an interrupted install needs restoring? Choose the same client
  folder, click Restore previous install, and keep LauSetupBackups in place.
- Restore stops because another update changed a game file? Keep the backup
  and all files. Report the exact message, filename, and a screenshot at
  https://github.com/CRSD-Lau/Lau-Setup/issues/new/choose. Do not delete or
  force-replace files to bypass the check.
- Setup reports a possible renamed upgrade patch or cannot safely check a
  patch? Keep the named archive and backups. Report the exact message, filename,
  and a screenshot at https://github.com/CRSD-Lau/Lau-Setup/issues/new/choose;
  do not delete, rename, or force-replace it to bypass the safety check.

Setup follows your system language. Use Interface language to select another
language; your choice is remembered for your user account. Automatic follows
the system again. Ten interface languages are bundled. This changes setup text
only, never WoW's nine game locales or language files.

Updating from an older release or test v2? Download the new installer first; old copies embed the old catalog.
Select the same client and visuals. File-hash checks detect the changed patches.
Start WoW and type /pyversion; it should report 3.0.8 Lau.

The installer detects your client language and HD model configuration.
Enhanced Consecration is selected by default. Uncheck it for the stock
appearance; the spell itself still works. New spell visuals require an
existing compatible HD model client. Upgraded maps/minimap are optional.

You need an existing WoW 3.3.5a client, build 12340. Windows 10/11 needs .NET
Framework 4.8. Linux needs the supported Wine/Mono environment in README.txt.
This download is an upgrade, not a complete client or language pack.
The required compatible WoW.exe is installed automatically.

No manual patch copying or renaming is needed. Do not download the entire
shared data release. The app downloads only the files needed for your selection.

Backups and resumable downloads stay in LauSetupBackups inside your WoW
folder, outside Data. To undo the update, close WoW, reopen Lau Setup, choose
the same folder, and click Restore previous install. Recovery also
works if an interrupted update left WoW.exe temporarily missing.

Your addons, SavedVariables, fonts, login artwork, realm settings, and
unrelated patches are preserved. No Pizza Warriors branding, personal
ElvUI setup, LoginUI, account data, or full game client is bundled.

Downloads come from GitHub Releases; no GitHub account is needed.
If a download stops, retry later. Verified files
are reused and partial downloads resume. Game files are changed only after
all required downloads have passed verification. Keep LauSetupBackups if
the app reports that recovery is needed.

This installer is unsigned, so Windows may display an unknown-publisher
warning. Use the supplied checksum to verify your download. It does not
require disabling Windows security or installing Python/PowerShell tools.
The .NET Framework 4.8 runtime is required.

Once this installer has added the map upgrade, it keeps that upgrade during
edition changes. Use Restore previous install to undo the map installation.
