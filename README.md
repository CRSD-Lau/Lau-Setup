# Lau Setup

A small Windows installer for the Lau 3.0.4 visual upgrade for an existing WoW 3.3.5a build 12340 client.

The installer selects the matching language files, offers visual options, and handles downloads, verified backups, patch placement, and recovery. It does not include a complete game client or personal UI settings.

The first installer release is being verified. Shared payloads are published separately for automatic download; users do not need to combine them manually.
